# Andrew Lengkong — Portfolio

Source code for Andrew Lengkong's responsive graphic-design portfolio.

## Live site

[andrew-lengkong-portfolio.lengkongandrew.chatgpt.site](https://andrew-lengkong-portfolio.lengkongandrew.chatgpt.site)

## Highlights

- Responsive editorial portfolio layout
- Custom hero photography and background artwork
- Animated entrances, ambient background motion, and shine effects
- About, capabilities, tools, and professional-experience sections
- Accessible reduced-motion support

## Local development

Requires Node.js 22.13 or newer.

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

The application uses React, TypeScript, Vinext, and Vite.
